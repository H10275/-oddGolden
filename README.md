# Modular Prime and Goldbach Framework

This repository contains a set of C++ modules designed to empirically test and model Goldbach's conjectures (even and odd), classify prime and composite numbers, and explore original mathematical hypotheses.

## 📁 Folder Structure

- `headers/`: C++ header files for model definitions
- `rsc/`: Input files, configuration data, and empirical results
- `EvenGoldbach/`: Models and tests for even-number Goldbach representations
- `OddGoldbach/`: Models and generators for odd-number Goldbach representations
- `PrimeModels/`: Empirical classification of prime numbers
- `CompositeModels/`: Modular classification of composite numbers
- `Conjectures/`: Hassan's original conjectures and generative logic
- `Tests/`: Range and single-value test cases
- `Docs/`: Bilingual documentation and theoretical background

## 🧪 Usage

1. Clone the repository and compile the desired `.cpp` file using a C++ compiler.
2. Provide input either manually or via files in `rsc/`.
3. Review output and compare with expected results in `rsc/expected_results.csv`.

## 📚 Documentation

All models are documented in both English and Arabic inside the `Docs/` folder. Each file includes:
- Mathematical background
- Empirical methodology
- Example inputs and outputs
- Interpretation of results
